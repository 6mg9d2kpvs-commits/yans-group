# YAN GROUP

Строительство домов и строительные услуги в Пермском крае.

[Открыть сайт](https://6mg9d2kpvs-commits.github.io/yans-group/)

Сайт содержит 16 страниц, каталог проектов, подбор комплектации и создание PDF в браузере. Автоматическая цена недоступна до утверждения тарифов. Отправка заявок пока не подключена; для связи доступны телефон и электронная почта на сайте.

## Публикация

`site.zip` содержит проверенную статическую сборку. Workflow `.github/workflows/pages.yml` распаковывает архив и публикует его в GitHub Pages. Для обновления замените архив новой проверенной сборкой и сохраните изменения в `main`.

Серверный исходный проект и его конфигурация сохраняются отдельно. Персональные данные из форм не отправляются в отсутствующий серверный обработчик; PDF формируется локально в браузере.

Перед публикацией проверены все страницы, мобильные размеры 320/390/768/1280 px, фильтры, галерея, параметры проектов, PDF, ссылка на расчёт, клавиатура и доступность WCAG A/AA. Настройка noindex сохранена.
